## What I do

- Check on which branch I am
- Create a new branch
- Ask clarifying questions about the branch you're supposed to create: the `<type>` and the `<name>` of the branch
- Always use check if there are a pre-prod and dev branch and use them as reference from creating the branch
- Never create a branch with the same name as an existing branch
- Never create a branch from another branch except from the main, pre-prod and dev branch ( ask question if needed )
- READ THESE REFERENCES BEFORE CREATING A BRANCH:
    - https://medium.com/@abhay.pixolo/naming-conventions-for-git-branches-a-cheatsheet-8549feca2534
    - https://git-scm.com/docs/git-branch

## When to use me

Use this when you want to create a new branch.
