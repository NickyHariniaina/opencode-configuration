## What I Do
- List all error in the codebase.
- Linter, compilation, tests errors.
- If there are any test, make sure they are passing, if they are not passing, list them in and tell why they are not passing.
- If there are any linter errors, list them in and tell why they are not passing.
- If there are any compilation errors, list them in and tell why they are not passing.
- Specify the file, line, and column number of the error.

## When to Use Me

Use this when you want to list all the errors in the codebase.
